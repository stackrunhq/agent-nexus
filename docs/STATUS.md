# 当前功能与下一步

更新：2026-09-09，开发版本 0.3。

## 已完成

| 范围 | 功能 |
| --- | --- |
| 模型接入 | 云端兼容 API、本地 vLLM 兼容 API、Ollama 原生对话和向量 |
| 统一处理 | 模型别名、能力校验、token 参数映射、用量和错误格式、超时及响应限制 |
| 模型工作台 | 配置编辑、启停、对话/向量试调用、耗时展示 |
| 修改记录 | 配置审计、筛选分页、事务一致性、ETag 并发保护 |
| 企业接入 API（本轮） | 创建企业、一次性签发机器凭据、轮换、停用、模型授权和撤销、事件记录 |
| 企业调用授权（本轮） | tenant 模式凭据识别、授权模型列表、对话/向量越权拦截 |
| 代码组织（本轮） | 按 models/tenants/storage/core/api/web 分包，路由与应用组装分离，测试按业务归档，提供代码和文档导航 |
| 企业管理页面（本轮） | React + TypeScript + Vite + Ant Design；企业创建、启停、凭据轮换、模型授权/撤销、最近事件；内存凭据及断开清理 |
| 个人身份（本轮） | 账号登录、1 小时可撤销会话、平台管理员/企业成员两角色、账号管理与密码重置、账号事件；0002 迁移 |
| 工程 | Docker/原生启动配置、依赖锁、CI、自动化测试、修改日志和逐步本地 Git 提交 |
| 数据存储 | SQLAlchemy 双数据库存储、Alembic 迁移、SQLite 导入；已在 PostgreSQL 17.11 实测 |
| 备份恢复（本轮） | 真实 pg_dump/pg_restore 演练、逐表一致性、恢复后的认证/API/序列验证、受限运行角色验证 |
| 故障诊断（本轮优化） | 零行就绪检查、数据库版本核验、独立 check 命令、统一数据库错误与请求 ID、连接池/锁等待限制 |

企业管理入口为 /admin/tenants，支持个人平台管理员登录，也保留环境管理员令牌用于初始接入。企业授权必须显式启用 tenant 模式；bootstrap 仅用于开发。

此前已完成按业务分包；本轮新增企业管理页面，基础个人身份已实现，完整组织权限仍待完善。代码入口见 [代码导航](architecture/CODE_MAP.md)。

本轮进一步完成顶层 api/web/cli/docker/image 职责划分与部署路径更新；React 企业管理页面已落地，详见 [技术架构](architecture/TECH_STACK.md)。

## 下一步顺序

1. 企业应用与版本管理，为知识库归属和发布建立基础；继续完善企业内角色、个人审计、自助改密与会话管理，并逐步迁移模型工作台。
2. 将已验证的数据库角色分离方案落实到生产部署配置，制定自动备份与恢复目标；基础实库/恢复演练已完成，见 BACKUP_RESTORE.md。
3. 企业用量、配额和限流；多密钥生命周期、个人审计身份。
4. 知识库：文件存储、后台解析、版本发布、中文混合检索及带引用问答。
5. 帮助中心：会话、真实流式响应、嵌入助手和分步操作指导。
6. 业务执行：流程模板、确认、连接器、幂等、审批回调和失败恢复。

## 验证范围

API/协议使用自动化测试，详细结果见 VALIDATION.md。真实模型服务、Docker 实际启动以及浏览器视觉交互尚未完成验证。当前不是完整企业知识库产品，也未达到多租户生产部署标准。
