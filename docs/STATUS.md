# 当前功能与下一步

更新：2026-09-10，开发版本 0.3。

## 已完成

本轮新增：小规模持久化向量索引和向量检索 API，绑定企业已授权 embedding 模型及已发布内容快照，数据库升级至 0005。见 [向量检索](VECTOR_SEARCH.md)。原知识库与关键词页面保持可用；向量管理页面、混合检索及引用问答仍待实现。

企业管理入口为 /admin/tenants，支持个人平台管理员登录，也保留环境管理员令牌用于初始接入。企业授权必须显式启用 tenant 模式；bootstrap 仅用于开发。

此前已完成按业务分包；本轮新增企业管理页面，基础个人身份已实现，完整组织权限仍待完善。代码入口见 [代码导航](architecture/CODE_MAP.md)。

本轮进一步完成顶层 api/web/cli/docker/image 职责划分与部署路径更新；React 企业管理页面已落地，详见 [技术架构](architecture/TECH_STACK.md)。
