# 当前功能与下一步

更新：2026-09-08，开发版本 0.3。

## 已完成

| 范围 | 功能 |
| --- | --- |
| 模型接入 | 云端兼容 API、本地 vLLM 兼容 API、Ollama 原生对话和向量 |
| 统一处理 | 模型别名、能力校验、token 参数映射、用量和错误格式、超时及响应限制 |
| 模型工作台 | 配置编辑、启停、对话/向量试调用、耗时展示 |
| 修改记录 | 配置审计、筛选分页、事务一致性、ETag 并发保护 |
| 企业接入 API（本轮） | 创建企业、一次性签发机器凭据、轮换、停用、模型授权和撤销、事件记录 |
| 企业调用授权（本轮） | tenant 模式凭据识别、授权模型列表、对话/向量越权拦截 |
| 工程 | Docker/原生启动配置、依赖锁、CI、自动化测试、修改日志和逐步本地 Git 提交 |
| 数据存储（本轮） | SQLAlchemy 双数据库存储、Alembic 初始迁移、SQLite 导入校验、PostgreSQL Compose 和集成测试配置；真实 PostgreSQL 尚未实测 |

目前企业接入通过 API 文档操作，工作台没有企业管理页面。企业授权必须显式启用 tenant 模式；bootstrap 仅用于开发。

## 下一步顺序

1. 完成 PostgreSQL 实库集成验证、备份恢复演练及最小权限角色配置；迁移和导入代码已交付，见 DATABASE.md。
2. 企业管理页面与身份：企业/客户组织/用户/角色/应用/版本；完整企业隔离与模型权限审查。
3. 企业用量、配额和限流；多密钥生命周期、个人审计身份。
4. 知识库：文件存储、后台解析、版本发布、中文混合检索及带引用问答。
5. 帮助中心：会话、真实流式响应、嵌入助手和分步操作指导。
6. 业务执行：流程模板、确认、连接器、幂等、审批回调和失败恢复。

## 验证范围

API/协议使用自动化测试，详细结果见 VALIDATION.md。真实模型服务、Docker 实际启动以及浏览器视觉交互尚未完成验证。当前不是完整企业知识库产品，也未达到多租户生产部署标准。
