# 持久化向量索引与检索

当前提供有界、小规模的向量检索 API。复用模型网关，支持已配置的 Ollama 原生 embedding，以及云端或本地 OpenAI-compatible embedding。向量以 JSON 快照保存在数据库，逐条计算余弦相似度；不是 pgvector/ANN，也没有混合检索或大模型问答。关键词检索保持独立。

## 升级与准备

1. 停止 API 和 Worker，备份数据库后执行 `python -m agent_nexus.db_cli upgrade`，升级到 **0005**。新增 knowledge_vector_indexes，当前共 14 张业务表。
2. 在模型工作台配置支持 embeddings 的模型别名、地址与凭据；本地模型仍需纳入 NEXUS_ALLOWED_HOSTS。
3. 在企业管理页面将该模型授权给目标企业。管理员建立索引也必须满足企业模型授权，避免无意把文档发给未授权模型。
4. 完成文档解析，发布产品版本及需要检索的文档。只索引当前可公开给本企业用户读取的分片，不包含草稿或撤回文档。

## 接口

管理员根路径：`/api/v1/admin/tenants/{tenant_id}/applications/{app_id}/versions/{version_id}`。

| 方法与路径 | 请求 | 行为 |
| --- | --- | --- |
| POST 根路径/vector-index | `{"model":"local-embed"}` | 同步建立或完整重建该版本/模型快照；完成返回维度和分片数 |
| GET 根路径/vector-index?model=local-embed | 无 | 返回 ready/stale、维度、已索引分片数；不存在返回 409/index_missing |
| POST 根路径/vector-search | `{"model":"local-embed","query":"如何更改登录密码","limit":5}` | 管理员按企业相同发布范围预览 |
| POST /api/v1/applications/{app_id}/versions/{version_id}/vector-search | 同上 | 使用企业机器凭据或企业成员会话查询，仍校验模型授权 |

文档与模型别名由请求明确指定；建立索引会把全部当前可读分片发送给该模型，搜索会发送问题。选择云端模型会发生外部传输并可能计费；本地模型调用本地配置端点。本轮测试仅使用模拟上游，未调用真实模型。

返回 method=vector_cosine、model 和 data；每项包含原文、文件名、文档摘要、文档/版本 ID、分片索引、页码/段落、字符偏移与 score。score 是相似度，不是答案可信度；当前无相关性阈值，即使无关问题也可能返回最近分片，不能把它当作已经回答问题。

## 一致性和边界

- 按版本和模型别名分别保存索引。每次重建使用同一模型配置快照，分批调用不会因后台中途修改配置而混用两个端点。
- 存储模型配置 ETag 与全部可读分片的摘要。模型配置、文档集合或来源内容变化后，查询返回 409/index_stale，要求重建；不会用新模型的查询向量匹配旧索引。
- 文档撤回会使整个快照失效；其余文档也需重建后才能向量查询。关键词检索仍可使用。应用停用/版本退役返回不可见，模型授权撤销拒绝请求。
- 嵌入调用前检查权限和快照，返回后再次检查；等待模型期间发生的文档撤回或授权变化会阻止输出原文。
- 全部向量成功并检查通过后，一次事务替换快照并写应用事件。失败不会覆盖原索引；原索引是否仍可用由其指纹决定。并发重建以最后一次成功提交为准，查询始终复核指纹。
- 同一上游模型名背后更换权重但配置和维度不变，系统无法自动识别。部署应使用固定版本模型名或更换别名，并明确重建索引。环境凭据轮换也不等同于模型版本识别。

当前每个快照 1–128 个分片，每批 16 个，最多 4096 维，JSON 快照最多 16 MiB，嵌入批次总时限 120 秒。拒绝零向量、非有限值及批次维度不一致。查询最多 200 字符、返回 1–20 项。超过范围明确拒绝，不局部索引或静默丢弃。没有持久化索引任务队列、进度、增量重建、索引删除接口或自动重建；原解析 Worker 不处理向量构建。

管理页面已接入模型选择、索引建立/重建和状态查询，并支持向量、混合检索与引用问答，操作与接口见 [混合检索与引用问答](ANSWERS.md)。扩大规模前需接入后台任务、配额与 pgvector 等索引方案。

代码位置：knowledge/vectors.py（快照、批次和检索）、vector_router.py（接口）、storage/vector_schema.py（表）、0005_vectors.py（冻结迁移）；models/gateway.py 的 embed_config 仅供内部固定配置调用。

更新：页面建立索引已切换至持久化后台任务；原同步 vector-index API 保留兼容。任务接口、租约和容量限制见 [索引任务](INDEX_JOBS.md)。
