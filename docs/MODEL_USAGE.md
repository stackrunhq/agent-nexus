# 企业模型调用账本

数据库 **0008** 新增 `model_calls`，共 17 张业务表。升级前停止 API、两个 Worker 并备份，执行 `python -m agent_nexus.db_cli upgrade` 后启动。账本随数据库备份、恢复与 SQLite 导入；运行角色需有该表读写权限。

覆盖企业直接 chat/embeddings、同步与后台索引的 embedding 批次、向量/混合检索、引用问答的 embedding 和 chat 调用。没有企业上下文的 bootstrap 调用与平台模型测试不记入企业账本；纯关键词检索不调用模型。

网关调用前写 pending，结果校验成功后写 succeeded；异常写 failed 和规范化错误码。记录模型别名、配置指纹、请求 ID、能力、时间、耗时及上游报告的输入/输出 token；不保存请求文本、文档、回答、向量或密钥。多个批次/问答调用用同一请求 ID 关联，各有独立记录 ID。

未知 token 保留 null，不视为零。不估算 token，也不换算价格。进程退出、取消或记账失败可能遗留 pending，表示结果未知，不自动归零或重发请求。账本初始写入失败时不调用模型；模型完成后写入失败时接口失败，客户端重试可能再次产生费用。

成功指网关返回有效模型响应，不表示最终业务成功：引用校验失败、授权撤销、索引保存失败之前，模型可能已经成功调用并计费。部分调用会在本地参数/凭据校验阶段失败；failed 不证明上游计费或未计费。

管理员接口：`GET /api/v1/admin/tenants/{tenant_id}/model-calls?offset=0&limit=20`。limit 1–100，offset 0–100000，按时间倒序、ID 稳定排序。不存在企业返回 404，无管理员身份拒绝访问。

页面：知识库 → 向量索引与检索 → 查看模型调用账本，显示该企业全部应用的调用，可刷新和翻页。当前没有按日期/模型筛选、汇总、导出、保留期清理或真实费用对账。

下一步在此账本基础上实现模型请求准入和检索/问答配额。现有索引任务额度保持不变；本轮不限制 chat/embedding token 或调用次数。pgvector 与真实模型质量评测仍待后续。
