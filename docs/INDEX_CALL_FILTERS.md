# 任务调用明细筛选

步骤 55（2026-09-16），数据库保持 0017，无新迁移。

管理员任务详情接口新增可选参数：

| 参数 | 值与范围 |
| --- | --- |
| attempt | 1、2、3、unknown；省略时不过滤尝试 |
| call_status | pending、succeeded、failed；省略时不过滤状态 |

attempt 与 call_status 可组合，服务端先筛选再分页。选择任意 attempt（包括 unknown）都仅返回本任务精确关联调用；unknown 表示精确关联但尝试次数缺失，不混入未确认归属的请求匹配。未指定 attempt 时保留原有精确关联和请求匹配范围。非法参数返回 422，资源鉴权和租户隔离不变。

详情页提供尝试和状态选择，以及清除筛选。每次筛选变化返回第一页，并取消之前尚未结束的请求。汇总卡片增加“查看本次调用”“查看本次失败调用”入口，无失败记录时禁用后者；未知尝试分组也可定位。刷新详情保留筛选并回首页。

summary 始终统计全任务全部精确关联调用，未确认调用数量也保持全任务范围，不受明细筛选或分页影响。空结果仅表示当前条件没有匹配调用，不能用于认定没有费用。结果仍是实时读取，不保证跨 SQL 快照一致性。

下一步增加调用错误码筛选与失败原因统计，让同一次尝试中不同失败原因更容易定位。
